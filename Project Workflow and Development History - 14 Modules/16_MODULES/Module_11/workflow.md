# Workflow

## Normal workflow

1.  Load tender list with current filters.
2.  User selects a tender to review analysis/documents/evidence.
3.  User records a bid/no-bid decision.

## Failure/retry workflow

-   If analysis data is missing or partial for a tender, the Dashboard shows what's available and flags the gap rather than failing to load the tender.

## Manual-review workflow

The Dashboard is itself the primary manual-review surface for uncertain classifications and analysis flagged by upstream modules.
