# 04 --- SYSTEM WORKFLOW

1.  Scheduler starts scanning.
2.  Load approved sources.
3.  Scan and record source health.
4.  Normalize results.
5.  Detect new/changed records.
6.  Filter software/IT opportunities.
7.  Collect documents.
8.  Extract text and OCR when needed.
9.  AI classify and analyze.
10. Store results.
11. Dashboard review.
12. Record bid/no-bid decision.

Security blocks are never bypassed; blocked sources go to manual review.
